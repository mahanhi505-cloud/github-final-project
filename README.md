# Simple Interest Calculator

A simple Bash-based calculator that computes simple interest using the principal amount, annual interest rate, and time period.

## Description

This project provides a simple interest calculator for a micro-finance organization. It demonstrates basic Bash scripting and supports the organization's transition to Git and GitHub.

## Formula

Simple Interest = (Principal × Rate × Time) / 100

Where:

* Principal is the initial amount of money.
* Rate is the annual interest rate expressed as a percentage.
* Time is the duration in years.

## Example

Principal: 1000
Annual Interest Rate: 5%
Time: 2 years

Simple Interest = (1000 × 5 × 2) / 100 = 100

## Usage

Run the `simple-interest.sh` script and enter the principal, annual interest rate, and time period when prompted.
